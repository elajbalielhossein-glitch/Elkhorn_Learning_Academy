EMPLOYEE EMAIL & CERTIFICATE EMAIL OPTION
- Admin must enter a valid employee email when creating an individual account.
- Employees can update their email in Employee Profile.
- The certificate page includes an Email Certificate button.
- Because this is an offline browser portal, the button opens the computer's default email application with the employee email, subject and certificate details filled in.
- Use Print or Save as PDF first, then attach the saved certificate PDF to the prepared email before sending.
- Fully automatic email delivery with a PDF attachment requires a hosted server, secure email service and database.
